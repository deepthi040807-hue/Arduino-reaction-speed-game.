# Two-Player Reaction Time Game (Arduino)

A two-player reaction speed game built on Arduino — LEDs signal "go," and whichever player presses their button first wins.

## Credit
Built by following the **Reaction Speed Game** project from **Robonyx Academy's** Arduino course. Core logic and circuit design are based on their tutorial.

## What I did
- Wired the full circuit myself (LEDs, buzzer, buttons) and got it working on a breadboard.
- Debugged a grounding issue — none of the components were working reliably until I realized all the ground connections needed to be tied to the same half of the breadboard's rail. Fixed the wiring and everything worked as expected.
- Tested and recorded a working demo (below).
